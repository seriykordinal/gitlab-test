# gitlab-test

Демонстрационный Go-проект с полностью настроенным CI/CD-пайплайном
в локальном GitLab, включая сборку и публикацию Docker-образа в Docker Hub.

## Что это за проект

Простое HTTP-приложение на Go, которое отвечает приветствием на запросы.

**Пример работы**

```bash
curl "http://localhost:8081/?name=Вася"
# Привет, Вася!!!
```

Если name не передается 

```bash
curl "http://localhost:8081/"
# Привет, мир!!!
```

Пайплайн состоит из 3 этапов


```bash
stages:
  - test
  - build
  - docker
```

## Этапы

**Тест**

Запуск Unit-теста


**Сборка**

Тестовая сборка исполняемого файла

**Сборка Docker image**

Сборка и отправление образа в Docker Hub

## Итог


После изменения кода можно закомитить изменения, и после успешного прохождения всех этапов CI/CD будет собран образ, который достаточно достать и запустить

```bash
docker pull your-dockerhub-username/gitlab-test:latest
docker run -p 8081:8081 your-dockerhub-username/gitlab-test:latest
```
